# ZipZipLang Compiler

Компилятор для языка программирования ZipZipLang, разработанный на Haskell с использованием библиотеки Parsec.

## Установка

```bash
cabal install zipziplang-compiler # в будущем, сейчас такого пакета на hackage.haskell.org нет, там сложно заслужить доверие
```

Или собрать из исходников:

```bash
git clone https://github.com/ruzen42/zipZipLangCompiler 
cd zipZipLangCompiler 
cabal build # или stack build
cabal install # или stack install соотвественно
```

## Использование

Компилятор запускается командой `zzc` с различными флагами:

### Основные команды

```bash
# Помощь по использованию
zzc -h
zzc --help

# Лексический анализ файла
zzc -l Main.hs

# Синтаксический анализ (AST дерево)
zzc -p Main.hs

# Компиляция файла
zzc Main.hs
```

### Флаги

- `-h, --help` - показать справку по использованию компилятора
- `-l` - выполнить только лексический анализ и вывести список токенов
- `-p` - выполнить синтаксический анализ и вывести AST дерево
- без флагов - полная компиляция файла

## Вывод ошибок

Компилятор выводит подробные сообщения об ошибках с указанием позиции в исходном файле:

```
unexpected character at line 5, column 12
```

## Системные требования

- GHC 9.2 или выше
- Cabal 3.0 или выше
- Библиотеки: parsec, base, optparse-applicative

## Разработка

Проект находится в активной разработке. Планируется реализация полного цикла компиляции в ближайших версиях.
